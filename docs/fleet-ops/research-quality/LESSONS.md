# Уроки ресёрча (LESSONS)

Живой опыт: что подвело и что помогло. **Читать перед каждой задачей** (скилл
`research/quality-loop`). Новый урок — после каждой задачи, где что-то пошло
не так или сработало неочевидное. Формат: правило — почему (факт) — дата.

1. **Не пиши факт в отчёт или wiki, не прочитав первоисточник в ЭТОЙ задаче.**
   Память модели конструирует правдоподобные цифры (seed llm-providers v1 был
   написан «по памяти» и почти попал в базу знаний непроверенным). — 22.10
2. **Прежде чем наблюдать URL — проверь живым fetch, что он содержит заявленное.**
   cons_doc_LAW_144025 оказался письмом Росреестра 2015, а не 273-ФЗ; «мониторинг
   закона» месяц смотрел бы не туда. — 22.10
3. **HTTP 200 ≠ живые данные.** Страница может быть JS-оболочкой без цен/текста;
   проверяй наличие ключевого паттерна (цена, название модели) в теле ответа. — 22.10
4. **Общий фид без фильтра = ежедневный шум.** vc.ru/rss без фильтра будит
   разбор новостей, нерелевантных домену. Фильтруй заголовки по домену. — 22.10
5. **Релей-провайдер подтверждает модель только зондом/attribution, не ценой
   и не названием.** plakcel: 234 имени моделей = один Qwen3-бэкенд. — факт #25
6. **Длинный ресёрч пиши поэтапно и рано.** Квотные стены роняют раны посреди
   работы (37 из 52 ранов октября — rate_limited); артефакт в workspace должен
   существовать с первого часа, а не в финале. — 08.10
7. **«Раздел оборван при извлечении» — не прочитанный раздел.** Переизвлеки
   целиком перед выводом (YPP «updated channel activity requirements»). — 22.10
