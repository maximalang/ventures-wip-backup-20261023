# База знаний (wiki-first)

Накапливаемая база знаний флота: `docs/knowledge/` в корне ventures-репо.
Знание компилируется один раз и поддерживается актуальным; каждый новый
ресёрч по теме стартует от страницы домена, а не с чистого листа.

## Когда активируется

Перед любым ресэрчем по теме, у которой может быть страница знаний, и при
закрытии любой research-карты.

## Контракт

1. **До ресёрча**: прочитай `docs/knowledge/<домен>.md`, если существует
   (список доменов — в `docs/knowledge/README.md`). Сверь свежесть фактов
   с их горизонтом; ключевые цифры старше горизонта перепроверь живым fetch.
2. **До закрытия задачи** (acceptance-шаг карты): обнови 1–3 страницы:
   - новые факты: URL-локатор + короткая подтверждающая цитата + `retrieved_at` + дата действия + статус;
   - устаревшее помечай `[deprecated YYYY-MM-DD]`, не удаляй молча;
   - допиши строку в «Историю обновлений» со ссылкой на артефакт задачи.
3. **Статусы фактов**: `verified` (цитата сверена по первоисточнику тобой в
   этой задаче) / `pending` (сообщено третьей стороной, не сверено — в
   выводах и рекомендациях не использовать) / `deprecated`.
4. **Разделяй** в странице: source facts / выводы (наша интерпретация с
   confidence) / unknowns.
5. **Свежесть по типу факта**: цены/промо — 14 дней; policy/условия — 90
   дней или до подписанного изменения; структурные факты — до нового события.
6. **Запись атомарная**: перезапиши файл целиком (tmp+rename), не append;
   в странице работает один исполнитель задачи за раз.
7. **Fact-store**: только устойчивые знания (вердикты, политика, структура
   рынка) с provenance и датой; не дублировать все цены.
8. Страница — кэш, не первоисточник: конфликт решает живой источник,
   страница обновляется под него.
9. Страницы нет, а тема recurring — создай по формату существующих
   (заголовок; retrieved_at+источник прохода; Source facts; Выводы;
   Unknowns/watch; История обновлений).

## Связанное

- Мониторинг доменов: `docs/fleet-ops/domain-watch/` (cron domain-watch
  обновляет эти же страницы по своим правилам статусов).
